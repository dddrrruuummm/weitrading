# WEI Trading

English corporate website for Wei trading LLC, an Ontario, California supplier of PPR, PE, PVC, valves, pumps, fittings, and related water-system products.

The site is designed for wholesale, retail, import sourcing, selected-area installation, and after-sales inquiries. Public company details and all replaceable contact information are centralized in `lib/site.ts`.

## Local development

```bash
npm install
npm run dev
```

## Production check

```bash
npm run build
```
